Use Case

Summary

The general contractor identifies construction defects on site, logs each defect as a BIM Collaboration Format (BCF) topic linked to the building model, triages and assigns it to the responsible trade subcontractor, verifies the rectification and closes the topic. A daily defect status report summarises the BCF topics for the owner's representative.

Aim and Scope

Aim: replace paper punch lists and spreadsheet defect logs with BCF topics that carry location, photographs, status and responsibility, so that every party works on the same defect record.

Benefits

One defect record from identification to closure; defects located in the model; measurable response times; fewer disputes about responsibility.

Limitations

BCF does not define defect-specific fields such as severity or root cause; they are carried as labels or comments by project convention (see the BCF extensions of the project).

import re
UUID = re.compile(r'^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$')

def check(topics):
    """topics: list of dicts with 'guid' and 'server_id'. Returns violations."""
    bad = [t['guid'] for t in topics if not UUID.match(t['guid'])]
    for key in ('guid', 'server_id'):
        seen = set()
        for t in topics:
            if t[key] in seen:
                bad.append(t[key])
            seen.add(t[key])
    return bad  # non-empty = violation

ALLOWED = {
    'Open': {'Assigned', 'Rejected'},
    'Assigned': {'In progress', 'Resolved'},
    'In progress': {'Resolved'},
    'Resolved': {'Closed', 'Reopened'},
    'Reopened': {'Assigned'},
}

def check(status_history):
    """status_history: statuses of one topic in time order."""
    return [(a, b) for a, b in zip(status_history, status_history[1:])
            if b not in ALLOWED.get(a, set())]  # non-empty = violation
